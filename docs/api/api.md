# REST API reference (`/api/v1`)

Interactive OpenAPI docs are generated by FastAPI at **http://localhost:8000/docs**.

## Conventions

* JSON request/response bodies; timestamps are ISO 8601 UTC.
* Authentication: `Authorization: Bearer <JWT>` from `POST /auth/login`.
* Roles: `VIEWER` < `OPERATOR` < `ADMIN` (a higher role includes the lower ones).
* Lists are paginated with `page` (≥1) and `page_size` (1–100) and return
  `{"items": [...], "total": n, "page": p, "page_size": s, "pages": k}`.
* Every error uses the same envelope:

```json
{"error": {"code": "INCIDENT_NOT_FOUND", "message": "Incident 42 not found", "details": null}}
```

| Status | Typical codes |
|---|---|
| 400 | `NO_CHANGES`, `EMPTY_FILE`, `INVALID_DATE_RANGE` |
| 401 | `NOT_AUTHENTICATED`, `INVALID_TOKEN`, `INVALID_CREDENTIALS` |
| 403 | `FORBIDDEN` |
| 404 | `*_NOT_FOUND`, `NOT_FOUND`, `SNAPSHOT_NOT_AVAILABLE` |
| 409 | `CAMERA_NAME_EXISTS`, `DETECTION_ALREADY_RUNNING`, `JOB_NOT_RUNNING`, `ALERT_ALREADY_ACKNOWLEDGED`, `INVALID_STATUS_TRANSITION` |
| 413 | `FILE_TOO_LARGE` |
| 415 | `UNSUPPORTED_FILE_TYPE` |
| 422 | `VALIDATION_ERROR`, `INVALID_CAMERA_SOURCE` |
| 429 | `TOO_MANY_JOBS` |
| 503 | `MODEL_NOT_AVAILABLE` |

## Endpoints

| Method | Path | Role | Description |
|---|---|---|---|
| GET | `/health` | public | DB status, detector mode, whether weights file exists (does not load the model) |
| POST | `/auth/login` | public | form fields `username` (e-mail), `password` → `{access_token, expires_in, user}` |
| GET | `/auth/me` | viewer | current user |
| GET | `/cameras?status=` | viewer | list cameras (credentials masked in `source_display`) |
| POST | `/cameras` | admin | create `{name, source_type: FILE|WEBCAM|RTSP, source_uri, location_id?}` |
| GET | `/cameras/{id}` | viewer | one camera, incl. `monitoring_job_id` |
| PUT | `/cameras/{id}` | admin | update fields (source changes require `source_uri`) |
| DELETE | `/cameras/{id}` | admin | 204; refused while monitoring; incidents keep history |
| GET | `/locations` | viewer | locations with `camera_count`, `active_incidents` *(added for the map page)* |
| POST | `/locations` | admin | create `{name, address?, latitude?, longitude?}` *(added)* |
| GET | `/detection/status` | viewer | model status (`READY` / `DEMO_MODE` / `MODEL_NOT_AVAILABLE`) and recent jobs |
| POST | `/detection/analyze` | operator | multipart `file` (+ optional `camera_id`) → 202 job |
| POST | `/detection/start` | operator | `{camera_id}` → 202 job monitoring that camera |
| POST | `/detection/stop` | operator | `{job_id}` or `{camera_id}` |
| GET | `/detection/jobs/{id}` | viewer | job progress, recent detections, incident ids *(added)* |
| GET | `/detection/jobs/{id}/snapshot` | viewer | latest processed frame (JPEG) with boxes *(added)* |
| GET | `/incidents` | viewer | filters: `hazard_type`, `severity`, `status`, `camera_id`, `location_id`, `active_only`, `date_from`, `date_to` |
| POST | `/incidents` | operator | manual report `{incident_type, severity, description?, camera_id?, location_id?}` → 201 |
| GET | `/incidents/{id}` | viewer | detail incl. detections, alerts, response actions, audit history |
| PATCH | `/incidents/{id}` | operator | `{status?, severity?, description?}`; status transitions are validated |
| GET | `/alerts` | viewer | filters: `status`, `severity`, `incident_id` |
| PATCH | `/alerts/{id}/acknowledge` | operator | 409 if already acknowledged |
| GET | `/dashboard/summary?days=14` | viewer | counts, breakdowns, daily series, model status — all computed from the DB |
| GET | `/system/config` | viewer | effective thresholds/weights/bands (no secrets) *(added)* |
| GET | `/system/logs` | operator | audit trail, filters `module`, `status` *(added)* |

### Incident status transitions

```
OPEN -> ACKNOWLEDGED | IN_PROGRESS | RESOLVED | FALSE_ALARM
ACKNOWLEDGED -> IN_PROGRESS | RESOLVED | FALSE_ALARM
IN_PROGRESS -> RESOLVED | FALSE_ALARM
RESOLVED | FALSE_ALARM -> OPEN (re-open)
```

## curl walkthrough

```bash
TOKEN=$(curl -s -X POST localhost:8000/api/v1/auth/login \
  -d "username=admin@example.com" -d "password=YOUR_PASSWORD" | python -c "import sys,json;print(json.load(sys.stdin)['access_token'])")
H="Authorization: Bearer $TOKEN"

curl -s -H "$H" localhost:8000/api/v1/detection/status
curl -s -H "$H" -F "file=@data/sample_videos/synthetic_fire_demo.mp4" localhost:8000/api/v1/detection/analyze
curl -s -H "$H" "localhost:8000/api/v1/incidents?active_only=true&page_size=10"
curl -s -H "$H" -X PATCH localhost:8000/api/v1/alerts/1/acknowledge
```
